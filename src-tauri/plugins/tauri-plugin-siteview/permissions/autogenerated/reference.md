## Default Permission

Shell-only control of the native site view. Never grant to a site webview.

#### This default permission set includes the following:

- `allow-open`
- `allow-close`
- `allow-set-rect`
- `allow-set-interactive-regions`
- `allow-navigate`
- `allow-go-back`
- `allow-go-forward`
- `allow-reload`
