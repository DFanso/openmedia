# OpenMedia

Load any website and reshape it: hide Instagram Reels, strip YouTube Shorts, remove anything you don't want. Customizations are declarative recipes; popular sites ship with bundled ones, and an AI assistant (bring your own API key) writes recipes for any other site. Desktop and mobile via Tauri. No backend.

**Status:** design phase, no runnable code yet. Start with the [wiki](docs/wiki/index.md) and the [roadmap](docs/wiki/roadmap.md). Contributors and agents: read [AGENTS.md](AGENTS.md).
